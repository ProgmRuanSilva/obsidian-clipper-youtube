This plugin adds the ability to transcribe YouTube videos into notes. It also adds a new note type for YouTube videos.

Based in the [forum discussion](https://forum.obsidian.md/t/web-clipper-youtube-video-transcript-for-yts-ui-feb-2026-update/111550/7) I made a template to unify all selectors at once for anyone who wants to use it.

## Installation

#### STEP 0 - Choosing you template style

##### 1. Only Transcription
![alt text](assets/raw.png)
##### 2. Timestamps 
![alt text](assets/timestamp.png)

1. Download the template.
2. Open the template file in Obsidian.
3. Click on the "Install" button.
   ![](assets/0-step.png)

#### STEP 1 - Open transcribe section automatically

After the template installation you need to open the transcription tab aways, you could have you own code or find aother solution for it, I'll explain using YouTube Tweaks plugin.

Install YouTube Tweaks in your browser: [Firefox](https://addons.mozilla.org/en-US/firefox/addon/tweaks-for-youtube/), [Chrome](https://chromewebstore.google.com/detail/tweaks-for-youtube/ogkoifddpkoabehfemkolflcjhklmkge), [Edge](https://microsoftedge.microsoft.com/addons/detail/tweaks-for-youtube/nnhifoobfibjmlkejadjmcdckkjbljcp)

#### STEP 2 - Configure YouTube Tweaks

1. Open the YouTube Tweaks extension.
2. Click on the "Preferences" button.
   ![](assets/1-step.png)
3. Go to the bottom.
4. Click on "Customize".
   ![](assets/2-step.png)
5. All done 🙃

#### STEP 3 Using the plugin

1. Open the Obsidian Web Clipper extension.
